# Tema Saràfatto

Tema custom per la presentazione del progetto. Il content model, le impostazioni e gli helper condivisi appartengono al plugin `sarafatto-core`.

## Asset

Da questa directory:

```sh
npm install
npm run dev
npm run build
```

Vite genera gli asset in `assets/dist`. `theme.json` è la fonte dei token condivisi con Gutenberg e Tailwind; le scelte di utilizzo sono in [`../../docs/DESIGN-SYSTEM.md`](../../docs/DESIGN-SYSTEM.md). I font WOFF2 attesi sono `assets/fonts/fraunces/fraunces-variable.woff2` e `assets/fonts/manrope/manrope-variable.woff2`.

Configurazione editoriale: [`../../docs/CONTENT-MODEL.md`](../../docs/CONTENT-MODEL.md). Menu e asset: [`../../docs/DEVELOPMENT.md`](../../docs/DEVELOPMENT.md). Polylang: [`../../docs/MULTILINGUAL.md`](../../docs/MULTILINGUAL.md).
